## E. 負面測試（文件裡沒有答案，必須承認找不到）

這幾題最重要 —— `rag_system.py` 的 prompt 明確要求找不到時回
「根據提供的文件資料，我無法找到關於『…』的具體資訊。」
若它自行編造答案，代表 prompt 沒有生效或檢索結果污染了上下文。

| # | 問題 | 期望回應 |
|---|---|---|

## F. 對話記憶測試（測 condense_question_prompt）

依序問，第二題刻意用代名詞，看它能否改寫成獨立問題：

1. 「曜石 V3 的算力多少？」
2. 「**它**的售價呢？」　→ 應理解為「曜石 V3 的售價是多少」，答 48,600 元（量產千片以上 41,300 元）
3. 「**前一代**呢？」　　→ 應理解為曜石 V2，答 18 TOPS / 12 瓦

若第 2、3 題答非所問，就是 `CONDENSE_QUESTION_PROMPT` 沒發揮作用。
